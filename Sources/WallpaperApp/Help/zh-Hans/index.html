1. 应用简介

Dynamic Wallpaper 是一款 macOS 本地动态壁纸管理工具，可将视频、动图、图片、本地网页或场景工程放到桌面，并通过播放列表轮换。

它适合希望桌面保持生动、按主题整理素材，或为不同显示器安排不同内容的用户。你可以直接应用单张壁纸，也可以设置列表顺序、停留时间、过渡和单项音量。应用提供简体中文、英语、日语、法语和西班牙语界面。

想做什么 从哪里开始 是否保存为正式配置
先看看效果 素材详情中的“播放预览” 否；停止预览后恢复原壁纸

设置系统屏保 侧栏“屏幕保护”中发布内容，再到 macOS 系统设置中选中屏保 与桌面壁纸分开保存

2. 快速开始

  1. 打开 Dynamic Wallpaper，点击工具栏的“导入壁纸”（加号），或按 ⌘O。
  2. 选择“媒体文件”，点击“选择文件…”，选中一个或多个视频、动图或图片，再确认导入。
  3. 在“全部壁纸”中点击素材，查看右侧“壁纸详情”。
  4. 选择目标显示器。默认“全部显示器 · 同步”会把同一来源应用到所有显示器；只想改变一块屏幕时，先改选该显示器。
  5. 选择“填满”或“完整显示”，点击“应用壁纸”。单张壁纸无需先加入播放列表。
  6. 视频需要声音时，关闭“全局静音”，再调整详情中的“此项静音”和“音量”，然后应用壁纸。
  7. 关闭主窗口后，正式壁纸会继续运行。点击菜单栏图标，可暂停、继续、切换列表、进入设置或重新打开主窗口。

💡 提示：点击“播放预览”会同时在详情栏和所选桌面临时预览。确认满意后仍需点击“应用壁纸”，才能保存为正式配置。

3. 功能详解

3.1 导入、查找与整理素材

素材库保存素材记录和新导入的独立副本，方便以后重复使用。

  1. 点击“导入壁纸”添加文件；也可将视频、动图或图片拖入主窗口。
  2. 在“搜索壁纸”中输入名称关键词，缩小当前结果范围。
  3. 选中素材后点击“收藏”，在“我的收藏”中快速找到常用内容。
  4. 点击“在 Finder 中显示”，定位应用使用的托管副本。

在播放列表页面导入时，新素材也会加入当前列表。从素材库移除素材，会同时移除所有列表中的相关条目，并清理其托管副本；从单个列表移除条目，只影响该列表，不删除副本。两者都不会删除原文件。

3.2 创建与播放列表

播放列表把多个素材排成一组，适合按主题轮播或让桌面定时变化。

  1. 在侧栏点击“新建播放列表”。
  2. 输入列表名称，点击“重命名”或按 Return 确认。
  3. 点击“添加壁纸”从素材库选择素材；也可在素材详情中用“加入播放列表”。
  4. 拖动条目，或点击其右侧上下箭头调整顺序。
  5. 选择播放模式、过渡、显示方式和目标显示器，再点击“应用播放列表”。
选项 可选值与默认值 实际效果与适用场景
播放模式 顺序循环（默认）；随机不重复；单项循环 顺序播放适合编排好的场景；随机适合减少重复；单项循环固定当前条目
过渡 直接切换；渐变 · 0.3 秒（默认）；渐变 · 0.8 秒 渐变同时作用于画面和声音；直接切换更干脆，也减少切换时的重叠处理
停留时长 固定时间（默认 30 秒）；完整播放一次；指定循环次数（初始 1 次） 选中条目后在详情中设置，并点击“保存时长”

固定时间可输入数值并选择 s（秒）、m（分钟）或 h（小时）；例如 1.5 m 等于 90 秒。视频和动图的完整播放、循环次数以素材本身时长计算。静态图片的完整播放使用所设时长；循环总时长为“所设时长 × 次数”。网页和场景仅支持固定时间。时长必须大于 0，循环次数必须为正整数。

“随机不重复”针对列表条目：同一素材加入两次，就算两个条目。“单项循环”下点击“下一张壁纸”仍会选择当前项；想换其他项，请先切换播放模式。下一项准备失败时会保留当前画面并显示错误，不会自动跳过。

菜单栏中的“播放列表”子菜单可快速应用列表，其目标是全部显示器，显示方式为“填满”。

3.3 为不同显示器安排壁纸

独立配置适合主屏与副屏用途不同；同步配置适合希望多块屏幕播放同一来源的场景。

  1. 应用单张素材或列表前，选择一台显示器，只修改该屏幕。
  2. 需要统一播放时，选择“全部显示器 · 同步”。
  3. 点击侧栏“显示器”，查看每台屏幕的当前来源与播放状态。
  4. 在显示器卡片中选列表、显示方式，再点击对应的应用按钮。更换单张素材，请回到素材库选择。
  5. 点击该屏幕的“恢复系统壁纸”，停止应用在该屏幕上的动态壁纸。

“填满”保持比例并裁剪超出部分；“完整显示”保留整幅画面，空余处显示黑色。同步组共用播放来源及相关声音设置。

⚠️ 注意：“恢复系统壁纸”是停止应用的桌面显示。如果之前开启了“同步系统底图”，系统仍会使用最近同步的静态图片，详见系统底图同步。

3.4 联动预览与声音控制

联动预览便于确认素材在真实桌面上的裁剪与显示效果，又不会保存显示器绑定。

  1. 选中素材或列表条目，指定显示器及显示方式。
  2. 点击“播放预览”。原来的正式播放会暂挂；目标属于同步组时，整组一起暂挂。
  3. 点击“停止预览”、换选素材，或关闭所属窗口，恢复原壁纸。

预览时只有详情栏输出声音，桌面副本保持静音；详情与桌面不保证逐帧同步。

调整位置 保存与生效范围
素材库详情的“此项声音” 用于当前预览；点击“应用壁纸”后保存到目标显示器，不改列表条目
列表条目详情的“此项声音” 保存到此条目，只影响该条目及其预览
“显示器”页面已应用单张壁纸的声音 即时更新当前壁纸；同步组共用设置，不改列表条目
“全局静音” 优先于所有单项设置，也会让预览静音

视频、网页和场景有单项声音设置，默认“此项静音”关闭、音量 100%。音量范围为 0–100%，每步 1%。需要安静桌面时优先使用全局静音；不同素材响度不一致时再逐项调节。

3.5 批量操作

  1. 点击“批量选择”，勾选条目；“全选当前结果”仅选中当前筛选结果。
  2. 在素材库中可批量收藏、取消收藏、加入列表或移除。
  3. 在列表中点击“批量编辑…”，勾选“修改停留时长”“修改静音”或“修改音量”，填写后点击“保存修改”。
  4. 点击“完成”退出批量选择。

三个修改开关默认均不勾选，未勾选的字段保持原值。编辑框的初始值是 30 秒、1 次、静音关闭、音量 100%，不是所选条目的共同值。所选项包含网页或场景时，批量时长仅能用固定时间；声音设置作用于视频、网页和场景。

3.6 本地网页壁纸与网页交互

本地网页项目适合使用 HTML、样式和脚本制作的桌面内容。

  1. 点击“导入壁纸”，选择“网页项目”。
  2. 点击“选择目录…”，选择包含网页与资源的项目文件夹。
  3. 指定“入口文件（HTML）”：默认 index.html；可点击“选择入口文件…”，或填写相对路径，如 pages/index.html。
  4. 点击“导入网页项目”，再从素材库应用。

导入会完整复制项目目录，保留相对路径，并将指向项目内部的符号链接展开为独立文件或目录；越界链接、循环链接及特殊文件会导致导入失败。导入后修改原项目不会自动同步到副本。网页及其图片、样式、脚本应放在项目目录内；项目外资源和外网访问仍受限制。暂停会保留当前画面；继续时会重新载入网页，网页内部进度不会保留。

需要操作网页时，点击菜单栏图标，开启“网页交互”（默认关闭）。按提示在 macOS 系统设置中允许“辅助功能”和“输入监控”，再返回菜单重新开启。授权被撤销后，交互会关闭。该功能转发 Finder 桌面空白处的左键点击，不等同于完整浏览器的交互方式。

3.7 为兼容性转换视频

当详情的兼容性检查确认视频适合转码时，会出现“转码…”。它用于生成更兼容的文件；是否可以使用此入口，以检查结果为准。

  1. 点击“转码…”，等待视频信息检查完成。
  2. 选择“原尺寸 · 原帧率”（默认），或“适配 1080p · 最高约 30 fps”。
  3. 确认输出目录和文件名。默认位于最初导入的来源目录，名称为 原文件名-h264.mp4；不允许将转码结果写入应用的 Media 目录或其子目录。
  4. 点击“加入转码队列”。完成后，点击任务上的“导入到素材库”，会另存独立托管副本，保留转码输出文件；需要时再替换列表中的条目。

关闭转码窗口后，可从菜单栏的“转码任务”重新查看进度。

输出为 H.264 视频、AAC 音频的 MP4，使用 VideoToolbox 硬件编码。重新编码并非无损；原尺寸方案会将奇数尺寸补为偶数，1080p 方案按比例缩小、不放大，并将帧率限制到最高约 30 fps。只保留第一条视频轨道和第一条音轨，不保留字幕、章节；原文件无音轨，输出仍无声。输出声音不受应用的静音或音量设置影响。

已有文件不会被覆盖。任务逐个执行，关闭转码窗口后仍继续；退出应用时会确认取消未完成任务，已完成文件保留。硬件编码失败会显示错误，不会自动换用软件编码。

3.8 同步系统底图

“同步系统底图”将正式壁纸定格成静态 PNG，并设为对应显示器的 macOS 系统壁纸，让动态层停止后仍有相近背景。

  1. 进入“设置 → 通用”，开启“同步系统底图”。
  2. 应用正式壁纸，查看各显示器的同步状态。
  3. 若显示失败，查看原因，处理后点击“重试同步”。

它不是逐帧更新的动态系统壁纸；临时预览不会写入底图。

⚠️ 注意：关闭同步、停止壁纸或退出应用，都会保留最后同步的图片，不会恢复开启同步之前的系统壁纸。要换回其他图片，请在 macOS 系统设置的“壁纸”中重新选择。

3.9 外观与全屏背景

macOS 26 及更高版本（包括 macOS 27）使用 Liquid Glass 玻璃材质；macOS 14 和 15 使用兼容的原生材质。可在“设置 → 外观”调整浅深色、透明度与模糊效果，以兼顾背景展示和文字清晰度。

主窗口进入当前活动的全屏空间时，可显示壁纸背景；普通窗口及后台空间不会持续进行这种全屏背景采集。没有应用壁纸时，使用系统壁纸的静态图片，不保证对应系统动态壁纸的当前时段画面。

3.10 设置原生屏保

侧栏的“屏幕保护”页独立管理系统屏保内容，不改变桌面壁纸。选择单个原生视频、图片、动图，或选择包含这些素材的播放列表；也可点“导入屏保素材…”添加本地文件。网页、场景和扩展播放器素材不会发布到屏保。导入或选择来源后，确认弹窗会居中列出纳入项；有不支持项时，纳入项与排除项左右并列。确认排除后才发布，原列表保持不变；新增排除项需要再次确认。

选择来源后，应用将媒体复制到应用支持目录的 DynamicWallpaper/ScreenSaverExport。页面只显示是否已有可用的发布内容；失败时显示错误，并保留上次成功发布的副本。相关列表变化会自动同步，也可点“立即同步”。新发布内容在屏保下次启动或重新打开应用内预览时生效，已运行的屏保继续使用它开始时的版本。删除原素材不会立刻删除已发布副本；“清除已发布屏保内容…”只清除屏保内容，不清空素材库或桌面设置，运行中的旧版本结束后才回收。

首次使用时，在屏保页点“安装或更新屏保…”，按 macOS 提示安装，然后自行在系统设置中选中 Dynamic Wallpaper Screen Saver。打开安装器后可点“重新检查安装状态”；已安装不代表系统已选中。进入该屏保的系统配置面板，授权屏保页显示的发布目录。屏保需要这项独立授权才能在主程序退出后读取已发布内容；目录移动、授权失效或未发布时会明确显示错误。应用内预览可先检查已发布画面，但系统屏保是否实际运行仍须在 macOS 中确认。

3.11 本地场景壁纸

  1. 选择“导入壁纸 → 场景项目”。
  2. 选择包含 project.json、场景 JSON 或 PKG 入口及完整资源的文件夹，不要单独选择 JSON/PKG 文件。
  3. 点击“导入场景项目”。应用保存独立副本，原目录之后的修改不会自动同步。
  4. 选中导入的场景，预览并选择显示器和显示方式，再点击“应用壁纸”。

请仅导入可信工程，因为场景脚本可以执行。元数据无效、路径越界或入口缺失会显示导入错误；资源应位于工程目录内。

场景使用固定停留时长。暂停会保留场景时钟，恢复时继续同一实例。现有的音量、静音、显示方式和网页帧率设置也适用于场景。开启现有交互设置并授予权限后，可接收鼠标移动和桌面空白处的左键点击；预览窗口可直接接收鼠标输入。

按作者默认属性播放。暂不支持场景编辑和原生屏保播放。兼容性取决于锁定版本的 WebWallGL；场景加载或渲染失败会显示错误；部分不兼容的效果或脚本可能仅产生引擎警告，记录在 CEF 日志中。不会自动替换为图片或视频。

开发版本新增可选的“系统音频响应”（设置 → 通用 → 声音），要求 macOS 14.2 或更新版本，默认关闭。首次采集时请允许系统音频录制。仅播放中的场景共用一个采集器，缩略图不会启动采集；壁纸静音不影响频谱输入。音频仅在内存中分析，排除本应用的声音，不录制文件、不上传、不使用麦克风。全部场景暂停或关闭、关闭此设置时停止采集。采集或设备出错时清空频谱并显示错误，场景画面继续播放；解决问题后点击“重试系统音频响应”。开发版本还提供可选的独立 Editor 应用。菜单栏 Editor 在已安装时直接打开；未安装时仅询问“下载 Editor”或“取消”。下载按钮打开官方发布页，不会自动安装。在 Editor 中通过“文件 → 在 Dynamic Wallpaper 中打开”导入已保存场景的副本，不会自动应用或加入播放列表。移除 Editor 保留已保存工程，不影响正常壁纸播放。已发布的 1.0.0 二进制尚不含此功能，Editor 尚未单独发布。

低电量模式时暂停 开／关；默认关 响应系统“低电量模式”，不是按某个电池百分比触发；移动办公时建议开启
设备温度较高时暂停 开／关；默认开 系统报告严重或临界热状态时暂停，建议保留开启

锁屏、系统或显示器休眠、用户会话不活跃时自动暂停，无需设置。所有自动暂停原因解除后才恢复；手动暂停必须手动继续。可在菜单栏查看暂停原因。

4.3 存储与素材、高级、关于

面板 内容 用途
存储与素材 独立副本说明、备份并清空素材库、最近配置备份与待清理数量 管理素材及清理状态，不改变原文件或应用设置

要重新建立素材库：

  1. 打开“设置 → 存储与素材”，点击“备份并清空素材库…”。导入进行中不能清空。
  2. 确认清除素材（含收藏）、播放列表和显示器绑定。应用设置、原文件与已同步的系统底图保持不变。
  3. 备份成功后才会清空记录并清理托管副本；可在“最近配置备份”下查看路径或在 Finder 中显示。

配置备份只包含 JSON，不包含媒体，不能恢复已删除的副本。相关转码仍占用素材时，请等待完成，或取消并等待资源释放后再试；无关转码不受影响。清理失败会显示错误并保留待清理记录，下次启动时重试。

如果素材已从库中消失、文件却仍在磁盘上，先查看“存储与素材”的待清理数量及错误详情。可能是托管目录已被替换或不是应用当前管理的副本，应用因此拒绝删除；这不表示原文件也被删除。不要直接清空整个素材目录，应先确认文件归属，再单独处理遗留副本。

4.4 语言与区域

  1. 打开“设置 → 通用 → 界面语言”。
  2. 选择“跟随系统”，或选择五种语言之一。
  3. 设置保存成功后，应用自己的界面立即更新，无需重启，也不会重启壁纸播放。

“跟随系统”按 macOS 首选语言顺序选择第一个受支持的语言；没有匹配时使用英语。数值显示随当前界面语言的区域格式变化，文件名、素材名和自定义列表名不会翻译。系统提供的菜单或文件选择窗口，可能仍按 macOS 自身语言显示。

从应用再次打开“帮助文档”，会重新使用当前应用语言；在帮助顶部选择其他语言，只改变这一次阅读的文档。

系统底图未同步，或停止后仍保留图片 同步未开启／等待正式壁纸；同步失败；最后一张系统图片被保留 ① 核对开关及显示器状态；② 正式应用一次；③ 排除文件或显示器问题后“重试同步”；④ 想换回其他底图时到 macOS“壁纸”中选择 关闭同步并自行设置系统壁纸；单纯关闭同步不会还原旧图

素材库读取失败时的“备份并重置”

只在应用明确提示素材库无法读取时使用。它会先备份现有配置，再清空素材记录、播放列表、显示器绑定及库内设置；原素材文件不删除。重置后需重新导入和配置。能够打开设置时，可先在“高级”中定位并另存配置文件；不要将重置作为黑屏或卡顿的第一步。

6. 性能与资源占用建议

  • 电池优先：开启“低电量模式时暂停”，保留高温暂停。长时间离开或不需要动画时，从菜单栏手动暂停。
  • 降低 CPU／GPU 负担：CPU 负责通用计算，GPU 负责图形处理。优先使用与屏幕需求相称的分辨率和帧率；转码入口可用时，1080p 方案适合更在意耗电的场景。
  • 多屏按用途分配：主屏用视频，副屏用图片，通常比每屏运行独立高清视频更轻。同步模式用于统一内容，但资源开销仍与屏幕数量和尺寸有关。
  • 减少重叠工作：用完及时停止预览；转码期间若有卡顿，先暂停壁纸。渐变切换会暂时处理前后两项，可改为“直接切换”。
  • 按需设置全屏背景：优先保留 30 Hz；确实需要更流畅的应用全屏背景时再选 60 Hz。该设置不限制桌面视频本身帧率。
  • 保持素材可读：常用素材存放在稳定连接的磁盘；网页尽量使用本地资源。无需同步静态底图时，可保持该功能关闭。
