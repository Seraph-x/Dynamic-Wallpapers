# Dynamic Wallpaper 1.1.1

Apple Silicon (arm64) · macOS 14.0 or later · build 6

This release reduces repeated work in thumbnails, library validation, audio edits and frame delivery, reorganizes the menu bar, and separates Editor into its own repository. Existing library data, scene import formats and application identity are retained.
