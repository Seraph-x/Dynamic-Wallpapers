# Dynamic Wallpaper 1.0.0 のインストール

Apple Silicon（arm64）· macOS 14.0 以降 · ビルド 4

1. 公式 GitHub Release から `DynamicWallpaper-1.0.0-arm64.dmg` と `SHA256SUMS.txt` を取得します。
2. `shasum -a 256 DynamicWallpaper-1.0.0-arm64.dmg` を実行し、対応するチェックサムと比較します。
3. DMG を開き、**Dynamic Wallpaper.app** を **Applications** にドラッグします。DMG を取り出してから起動します。ZIP 版は展開後にアプリを Applications へ移動します。
4. アドホック署名であり、Apple の公証は受けていません。起動がブロックされた場合はダウンロードを確認し、システム設定のプライバシーとセキュリティからこのアプリを許可してください。

旧版を通常終了してから置き換えてください。素材データはアプリとは別に保存されます。ダウングレードが必要なら、初回起動前に `~/Library/Application Support/DynamicWallpaper` を別にコピーしてください。1.0.0 はライブラリ形式 4 を保存するため、旧版は更新後の設定を読めない場合があります。「バックアップしてライブラリを消去」は現在のライブラリも消去します。

壁紙の読み込みでメディア、Web、シーンの種類を選択し、表示先を選んで適用します。シーンのフォルダには `project.json`、JSON・PKG の開始ファイルと素材が必要です。信頼できるプロジェクトのみ使用してください。シーンは一時停止位置から再開し、Web は再読み込みします。

アプリ内のユーザーガイドはオフラインで読めます。シーンの互換性は効果やスクリプトによります。システム音声スペクトラム、シーン編集、シーンのスクリーンセーバー再生は非対応です。第三者ソース・ライセンス資料の未解決事項は ThirdParty とリリースノートに記載されています。
