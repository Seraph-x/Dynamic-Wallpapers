# Dynamic Wallpaper 1.1.0 のインストール

Apple Silicon（arm64）· macOS 14.0 以降 · ビルド 5

1. 公式 GitHub Release から `DynamicWallpaper-1.1.0-arm64.dmg` と `SHA256SUMS.txt` を取得します。
2. `shasum -a 256 DynamicWallpaper-1.1.0-arm64.dmg` を実行し、対応するチェックサムと比較します。
3. DMG を開き、**Dynamic Wallpaper.app** を **Applications** にドラッグします。DMG を取り出してから起動します。ZIP 版は展開後にアプリを Applications へ移動します。
4. アドホック署名であり、Apple の公証は受けていません。起動がブロックされた場合はダウンロードを確認し、システム設定のプライバシーとセキュリティからこのアプリを許可してください。

旧版を通常終了してから置き換えてください。素材データはアプリとは別に保存されます。ダウングレードが必要なら、初回起動前に `~/Library/Application Support/DynamicWallpaper` を別にコピーしてください。1.1.0 はライブラリ形式 4 を保存するため、旧版は更新後の設定を読めない場合があります。「バックアップしてライブラリを消去」は現在のライブラリも消去します。

壁紙の読み込みでメディア、Web、シーンの種類を選択し、表示先を選んで適用します。シーンのフォルダには `project.json`、JSON・PKG の開始ファイルと素材が必要です。信頼できるプロジェクトのみ使用してください。シーンは一時停止位置から再開し、Web は再読み込みします。

アプリ内のオフラインガイドで、シーンプロパティ、Music・Spotify の明示的な許可、音声への反応を確認できます。システム音声への反応は macOS 14.2 以降が必要で、その他の機能は macOS 14.0 以降に対応します。シーンのネイティブスクリーンセーバー再生は未対応です。Editor 0.1.0 は別途取得する任意のアプリで、プロジェクトと設定は独立しています。

Main を削除するには終了後、**Dynamic Wallpaper.app** だけをゴミ箱へ移動します。任意のスクリーンセーバーをインストールした場合はシステム設定で別途削除してください。素材は `~/Library/Application Support/DynamicWallpaper/` に残ります。ライブラリを消去したい場合だけそのフォルダを削除してください。Editor とそのプロジェクトは削除されません。ThirdParty に管理されたビルドのソース、ライセンス、実測記録を保持しています。検証範囲はリリースノートを参照してください。
