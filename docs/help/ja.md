## 1. アプリについて {#introduction}

Dynamic Wallpaper は、Mac に保存した動画、アニメーション、画像、ローカル Web プロジェクトをデスクトップの壁紙として表示し、プレイリストで切り替えられる macOS アプリです。

動きのあるデスクトップを楽しみたいとき、テーマごとに素材を整理したいとき、ディスプレイごとに異なる内容を表示したいときに便利です。1 つの素材をすぐに適用することも、プレイリストの順序、表示時間、切り替え効果、項目ごとの音量を調整することもできます。表示言語は簡体字中国語、英語、日本語、フランス語、スペイン語に対応しています。

| 目的 | 最初の操作 | 正式な設定として保存されるか |
| --- | --- | --- |
| 見た目を確認する | 素材の詳細で「プレビューを再生」 | いいえ。終了後は元の壁紙に戻ります |
| デスクトップを設定する | 「壁紙を適用」または「プレイリストを適用」 | はい。メインウインドウを閉じても動作します |
| macOS のスクリーンセーバーを設定する | 「スクリーンセーバー」で公開し、macOS のシステム設定で選択 | デスクトップとは別に保存されます |

## 2. 使い始める {#quick-start}

1. Dynamic Wallpaper を開き、ツールバーの「壁紙を読み込む」（プラスボタン）をクリックします。`⌘O` でも開けます。
2. 「メディアファイル」を選び、「ファイルを選択…」をクリックします。動画、アニメーション、画像を 1 つ以上選んで読み込みます。
3. 「すべての壁紙」で素材をクリックし、右側の「壁紙の詳細」を開きます。
4. 表示先を選びます。初期値の「すべてのディスプレイ · 同期」は、すべての画面に同じ再生元を適用します。1 台だけ変更する場合は、そのディスプレイを選んでください。
5. 「画面全体に表示」または「全体を表示」を選び、「壁紙を適用」をクリックします。単一の壁紙にプレイリストは不要です。
6. 動画の音を出す場合は「すべてミュート」をオフにし、詳細の「この項目をミュート」と「音量」を調整してから壁紙を適用します。
7. メインウインドウを閉じても、適用済みの壁紙は再生を続けます。メニューバーのアイコンから、一時停止、再開、プレイリストの切り替え、設定、メインウインドウの再表示を行えます。

> 💡 **ヒント**：「プレビューを再生」をクリックすると、詳細欄と選択したデスクトップで一時的に確認できます。正式な設定として保存するには、その後「壁紙を適用」をクリックしてください。

## 3. 機能の使い方 {#features}

### 3.1 素材を読み込み、探し、整理する {#library}

ライブラリには素材の記録と、新しく読み込んだ素材の独立したコピーが保存され、繰り返し利用できます。

1. 「壁紙を読み込む」からファイルを追加します。動画、アニメーション、画像をメインウインドウへドラッグすることもできます。
2. 「壁紙を検索」に名前の一部を入力し、結果を絞り込みます。
3. 素材を選んで「お気に入り」をクリックすると、「お気に入り」ページからすぐに見つけられます。
4. 「Finder に表示」をクリックすると、アプリが使用する管理コピーを確認できます。

プレイリストを表示中に読み込むと、そのリストにも素材が追加されます。ライブラリから素材を削除すると、すべてのリストの該当項目と管理コピーが削除されます。1 つのリストから項目を削除するだけなら、そのリストだけが変わり、コピーは残ります。どちらも元ファイルは削除しません。

### 3.2 プレイリストを作成して再生する {#playlists}

複数の素材をまとめると、テーマに沿って順番に表示したり、一定時間ごとに壁紙を変えたりできます。

1. サイドバーの「プレイリストを作成」をクリックします。
2. 名前を入力し、「名前を変更」をクリックするか、Return キーで確定します。
3. 「壁紙を追加」からライブラリの素材を選びます。素材の詳細にある「プレイリストに追加」も利用できます。
4. 項目をドラッグするか、右側の上下矢印で順序を調整します。
5. 再生モード、切り替え効果、表示方法、表示先を選び、「プレイリストを適用」をクリックします。

| 項目 | 選択肢と初期値 | 効果と使いどころ |
| --- | --- | --- |
| 再生モード | 順番にループ（初期値）、重複なしでランダム、1 項目をループ | 決めた順序で見たいときは順番再生、変化を楽しみたいときはランダム、同じ項目を続けたいときは 1 項目のループ |
| 切り替え | 即座に切り替え、フェード · 0.3 秒（初期値）、フェード · 0.8 秒 | フェードは映像と音声の両方に作用します。即時切り替えは区切りが明確で、前後の素材を同時処理する負荷も抑えられます |
| 表示時間 | 固定時間（初期値 30 秒）、最後まで 1 回再生、回数を指定してループ（初期値 1 回） | 項目を選び、詳細で変更して「時間を保存」をクリックします |

固定時間には数値と s（秒）、m（分）、h（時間）の単位を指定できます。たとえば 1.5 m は 90 秒です。動画とアニメーションの全体再生・ループには、素材本来の長さを使います。静止画の全体再生には指定時間を使い、ループ時の合計は「指定時間 × 回数」です。Web 壁紙は固定時間のみです。時間は 0 より大きい値、回数は正の整数を指定してください。

「重複なしでランダム」はリストの項目単位で判定します。同じ素材を 2 回追加すれば、別々の項目です。「1 項目をループ」では「次の壁紙」をクリックしても現在の項目が選ばれるため、別の項目へ進むには再生モードを変更してください。次の項目を準備できない場合は現在の画面を保ち、エラーを表示します。自動的にはスキップしません。

メニューバーの「プレイリスト」サブメニューから選ぶと、すべてのディスプレイに「画面全体に表示」で適用されます。

### 3.3 ディスプレイごとに設定する {#displays}

メイン画面とサブ画面の用途が異なるときは個別設定、同じ再生元を表示したいときは同期設定が便利です。

1. 単一の素材やリストを適用する前に、変更したいディスプレイを 1 台選びます。
2. 共通の内容を再生する場合は「すべてのディスプレイ · 同期」を選びます。
3. サイドバーの「ディスプレイ」を開き、各画面の再生元と状態を確認します。
4. 各カードでリストと表示方法を選び、対応する適用ボタンをクリックします。単一の壁紙を別の素材に変える場合は、ライブラリに戻って選んでください。
5. その画面でアプリの壁紙を停止するには、「システムの壁紙に戻す」をクリックします。

「画面全体に表示」は縦横比を保ち、画面からはみ出す部分を切り取ります。「全体を表示」は画像全体を表示し、余白は黒くなります。同期グループでは、再生元と関連する音声設定を共有します。

> ⚠️ **注意**：「システムの壁紙に戻す」はアプリのデスクトップ表示を停止する操作です。「システム壁紙を同期」を使っていた場合、macOS には最後に同期した静止画が残ります。[システム壁紙の同期](#system-wallpaper)も確認してください。

### 3.4 連動プレビューと音声調整 {#preview-audio}

連動プレビューでは、ディスプレイへの割り当てを保存せずに、実際のデスクトップで表示範囲や切り取りを確認できます。

1. 素材またはリスト項目を選び、表示先と表示方法を指定します。
2. 「プレビューを再生」をクリックします。元の再生は一時的に中断されます。対象が同期グループに属する場合は、グループ全体が中断されます。
3. 「プレビューを停止」をクリックする、別の素材を選ぶ、またはプレビュー元のウインドウを閉じると、元の壁紙に戻ります。

プレビュー音声は詳細欄からのみ出力され、デスクトップ側はミュートされます。詳細欄とデスクトップの映像がフレーム単位で一致するとは限りません。

| 音声を変更する場所 | 保存先と適用範囲 |
| --- | --- |
| ライブラリ詳細の「この項目のサウンド」 | 現在のプレビューに使われ、「壁紙を適用」で対象ディスプレイに保存されます。リストの音声設定は変わりません |
| リスト項目の詳細にある「この項目のサウンド」 | その項目に保存され、その項目とプレビューだけに作用します |
| 「ディスプレイ」で適用済みの単一壁紙の音声 | 現在の壁紙へすぐ反映されます。同期グループで共有され、リストの設定は変わりません |
| 「すべてミュート」 | 個別設定より優先され、プレビューもミュートします |

個別の音声設定は動画と Web 壁紙にあります。初期値は「この項目をミュート」がオフ、音量が 100% です。音量は 0～100% を 1% 刻みで調整できます。静かなデスクトップにしたいときは全体をミュートし、素材ごとの音量差が気になるときは個別に調整してください。

### 3.5 複数項目をまとめて操作する {#batch}

1. 「複数選択」をクリックして項目を選びます。「現在の結果をすべて選択」は、現在の絞り込み結果を選びます。
2. ライブラリでは、お気に入りの追加・解除、リストへの追加、削除をまとめて行えます。
3. リストでは「一括編集…」をクリックします。「表示時間を変更」「ミュート設定を変更」「音量を変更」のうち必要な項目をオンにして入力し、「変更を保存」をクリックします。
4. 「完了」をクリックすると、複数選択が終了します。

3 つの変更スイッチは最初すべてオフです。オンにしない設定は元のまま残ります。入力欄の初期値は 30 秒、1 回、ミュートオフ、音量 100% であり、選択した項目の共通値を示すものではありません。Web 項目を含む場合、時間の一括編集は固定時間のみです。音声の変更は動画と Web 壁紙だけに作用します。

### 3.6 ローカル Web 壁紙と Web 操作 {#web}

ローカル Web プロジェクトは、HTML、スタイル、スクリプトで作ったデスクトップ用コンテンツに利用できます。

1. 「壁紙を読み込む」をクリックし、「Web プロジェクト」を選びます。
2. 「フォルダを選択…」をクリックし、ページとリソースが入ったフォルダを選びます。
3. 「開始ファイル（HTML）」を指定します。初期値は `index.html` です。「開始ファイルを選択…」を使うか、`pages/index.html` のような相対パスを入力します。
4. 「Web プロジェクトを読み込む」をクリックし、ライブラリから適用します。

読み込み時はプロジェクトフォルダ全体をコピーし、相対パスを保ちます。プロジェクト内部を指すシンボリックリンクは独立したファイルやフォルダに展開され、外部へのリンク、循環リンク、特殊ファイルがあると読み込みに失敗します。読み込み後に元プロジェクトを変更してもコピーには同期されません。HTML、画像、スタイル、スクリプトはプロジェクト内にまとめてください。外部ファイルや外部ネットワークへのアクセスは引き続き制限されます。一時停止中は画面を保持し、再開時はページを読み込み直すため、内部の進行状態は引き継がれません。

操作するには、メニューバーから「Web 操作」をオンにします（初期値はオフ）。案内に従って macOS のシステム設定で「アクセシビリティ」と「入力監視」を許可し、メニューに戻ってもう一度オンにしてください。許可を取り消すと操作機能はオフになります。Finder のデスクトップの空白部分での左クリックを転送する機能であり、通常のブラウザと同じ操作一式を提供するものではありません。

### 3.7 互換性のために動画を変換する {#transcoding}

詳細欄の互換性チェックで変換対象と判断された動画には、「変換…」が表示されます。より互換性の高い新しいファイルを作るための機能で、利用できるかどうかはチェック結果によって決まります。

1. 「変換…」をクリックし、動画の確認が終わるまで待ちます。
2. 「元のサイズ・フレームレート」（初期値）、または「1080p に調整 · 最大約 30 fps」を選びます。
3. 出力先とファイル名を確認します。初期値は最初に読み込んだ元ファイルのフォルダ、名前は `元のファイル名-h264.mp4` です。アプリの `Media` フォルダやその配下には出力できません。
4. 「変換キューに追加」をクリックします。完了したタスクの「ライブラリに読み込む」で独立した管理コピーを作り、変換後の出力ファイルも残します。必要に応じてリストの項目を差し替えます。

ウインドウを閉じた場合は、メニューバーの「変換タスク」から開き直して進捗を確認できます。

VideoToolbox によるハードウェアエンコードで、H.264 動画と AAC 音声の MP4 を作成します。再エンコードのため、無劣化のコピーではありません。元のサイズを使う場合は奇数の寸法を偶数になるよう補い、1080p 設定では比率を保って縮小し、拡大せず、最大約 30 fps に制限します。最初の動画トラックと音声トラックだけを保持し、字幕やチャプタは残しません。元の動画に音声がなければ、出力も無音です。アプリのミュートや音量は、出力ファイルの音声に影響しません。

既存ファイルは上書きしません。タスクは順番に実行され、変換ウインドウを閉じても継続します。アプリ終了時は未完了タスクの取り消しを確認し、完成済みのファイルは残します。ハードウェアエンコードに失敗した場合はエラーを表示し、自動的にソフトウェアエンコードへ切り替えません。

### 3.8 システム壁紙を同期する {#system-wallpaper}

「システム壁紙を同期」は、適用済みの壁紙を PNG の静止画にして、その画面の macOS 壁紙に設定します。動的な表示を停止しても、近い見た目の背景を残せます。

1. 「設定 → 一般」で「システム壁紙を同期」をオンにします。
2. 壁紙を正式に適用し、各ディスプレイの同期状態を確認します。
3. 失敗した場合は原因を確認し、対処後に「同期を再試行」をクリックします。

毎フレーム更新するシステム壁紙ではありません。一時的なプレビューからは書き込みません。

> ⚠️ **注意**：同期をオフにする、壁紙を停止する、アプリを終了する、いずれの場合も最後に同期した画像が残ります。同期前のシステム壁紙には戻りません。別の画像に戻す場合は、macOS のシステム設定の「壁紙」で選び直してください。

### 3.9 外観とフルスクリーン背景 {#appearance}

macOS 26 以降（macOS 27 を含む）では Liquid Glass、macOS 14 と 15 では互換性のある標準のマテリアルを使います。「設定 → 外観」で明暗、透明度、ぼかしを調整すると、背景の見え方と文字の読みやすさを両立できます。

メインウインドウが現在操作中のフルスクリーンスペースにあるとき、壁紙を背景に表示できます。通常のウインドウや背後のスペースでは、この背景の連続キャプチャは行いません。アプリの壁紙がない場合はシステム壁紙の静止画を使いますが、macOS のダイナミック壁紙の現在の時間帯の画像と一致するとは限りません。

### 3.10 ネイティブスクリーンセーバーを設定する {#screensaver}

サイドバーの「スクリーンセーバー」では、デスクトップの壁紙とは別にシステム用の内容を管理します。ネイティブ動画、静止画、アニメーション、またはそれらを含むプレイリストを選びます。「スクリーンセーバー用素材を読み込む…」からローカルファイルも追加できます。Web 項目と拡張プレーヤーの素材は公開対象から除外されます。読み込み後またはソース選択後の確認画面では、含める項目を中央に表示します。除外項目がある場合は、含める項目と除外項目を左右に並べて表示します。除外を承認してから公開します。元のプレイリストは変わらず、新しい除外項目には再確認が必要です。

公開する素材はアプリケーションサポート内の `DynamicWallpaper/ScreenSaverExport` にコピーされます。画面には利用可能な内容が公開済みかどうかだけを表示します。同期失敗時はエラーを表示し、前回成功したコピーを残します。関連するプレイリストの変更は自動同期され、「今すぐ同期」でも公開できます。新しい内容はスクリーンセーバーの**次回起動時**、またはアプリ内プレビューを開き直したときに反映されます。実行中の画面は開始時の版を使い続けます。元の素材を削除しても公開済みコピーは直ちには消えません。「公開済みスクリーンセーバー内容を消去…」はスクリーンセーバーの内容だけを消去し、実行中の古い版は終了後に回収されます。

初回はこの画面で「スクリーンセーバーをインストール／更新…」を押し、macOS の案内に従ってください。その後、システム設定で **Dynamic Wallpaper Screen Saver** を自分で選択します。「インストール状態を再確認」で確認できますが、インストール済みでも選択済みとは限りません。システムのスクリーンセーバー設定画面で、アプリに表示された公開フォルダーへのアクセスを許可します。これはアプリ終了後の読み取りにも必要です。フォルダーの移動、許可の失効、未公開の内容は明確なエラーになります。アプリ内プレビューとは別に、macOS 上で実際の動作を確認してください。

## 4. 設定項目 {#settings}

以下は新しいライブラリの初期値です。既存の設定は引き継がれます。通常の設定は変更後すぐに保存・反映されます。「時間を保存」などの保存ボタンがある編集は、ボタンをクリックして確定してください。

### 4.1 一般 {#general-settings}

| 設定 | 選択肢／初期値 | 効果と推奨設定 |
| --- | --- | --- |
| 表示言語 | システムに従う（初期値）、简体中文、English、日本語、Français、Español | アプリの表示言語を指定します。下の言語の説明も参照してください |
| ログイン時に起動 | オン／オフ。新規インストール時は未登録 | macOS へのログイン後に起動します。承認が必要な場合は「システムのログイン項目設定を開く…」から確認します |
| Dock にアプリアイコンを表示 | オン／オフ。初期値はオン | オフの場合も、管理ウインドウを開くと Dock アイコンとアプリメニューを一時的に表示し、すべて閉じるとアイコンを非表示にします。最小化や非表示は閉じたことにはなりません。保存済みの設定は変わりません。壁紙は停止せず、省電力のための設定でもありません |
| システム壁紙を同期 | オン／オフ。初期値はオフ | 正式な壁紙を静止画にしてシステム壁紙へ書き込みます。画像生成とディスク書き込みを伴うため、不要ならオフのままにします |
| すべてミュート | オン／オフ。初期値はオン | 動画、Web、プレビューの音声をまとめて消します。個別の音量値は 0 に変更されません |
| 低電力モードで一時停止 | オン／オフ。初期値はオフ | macOS の低電力モードに反応します。特定のバッテリー残量を判定する設定ではありません。バッテリー使用時に便利です |
| デバイスが高温のときに一時停止 | オン／オフ。初期値はオン | システムが深刻または危機的な熱状態を報告したときに停止します。オンのままを推奨します |

画面ロック、システムやディスプレイのスリープ、ユーザーセッションが非アクティブなときは、自動で一時停止します。設定は不要です。自動停止の原因がすべて解消してから再開します。手動で停止した場合は手動で再開してください。停止理由はメニューバーで確認できます。

### 4.2 外観 {#appearance-settings}

| 設定 | 選択肢／初期値 | 効果と留意点 |
| --- | --- | --- |
| 外観モード | システムに従う（初期値）、ライト、ダーク | 壁紙ファイルではなくアプリの外観を変えます。周囲の明るさに合わせて選びます |
| 背景の透明度 | 0～100%。初期値は 75% | 100% はぼかしなしの完全な透明、0% は不透明です。複雑な背景で文字が読みにくい場合は透明度を下げます |
| ぼかし効果 | クリア、すりガラス（初期値） | 透明度が 100% 未満のときに使います。すりガラスは手前の内容を読みやすくします |
| フルスクリーン背景のフレームレート | 30 Hz（初期値）、60 Hz | アプリのフルスクリーン背景のキャプチャ頻度です。デスクトップ動画の上限ではありません。60 Hz は滑らかですが処理負荷が増えます |

macOS の「透明度を下げる」がオンの場合は、システムの読みやすさの設定が優先されます。アプリに保存した透明度とぼかしの値は上書きされません。

### 4.3 ストレージ、詳細設定、アプリ情報 {#other-settings}

| パネル | 内容 | 用途 |
| --- | --- | --- |
| ストレージ | 独立コピーの説明、バックアップとライブラリの消去、最新の設定バックアップ、削除待ち件数 | 元ファイルやアプリ設定を変えずに、素材と削除状況を管理します |
| 詳細設定 | 設定ファイル名、ライブラリ形式のバージョン、完全なパス、「Finder に表示」 | 読み取り専用の情報です。設定ファイルの場所確認やバックアップに使います |
| アプリ情報 | アプリ名、バージョン、説明 | 使用中のバージョンを確認します |

ライブラリを空にして整理し直すには：

1. 「設定 → ストレージ」で「バックアップしてライブラリを空にする…」をクリックします。読み込み中は実行できません。
2. お気に入りを含む素材、プレイリスト、画面への割り当ての削除を確認します。アプリ設定、元ファイル、同期済みのシステム画像は変わりません。
3. バックアップに成功した後でのみ、記録と管理コピーを削除します。「最新の設定バックアップ」でパスを確認するか、Finder に表示できます。

バックアップは JSON のみでメディアを含まず、削除したコピーは復元できません。関連する変換タスクが素材を使用中の場合は、完了するか、キャンセル後のリソース解放を待って再実行してください。無関係なタスクには影響しません。削除に失敗するとエラーと削除待ち記録が残り、次回起動時に再試行します。

素材がライブラリから消えたのにファイルが残る場合は、「ストレージ」の削除待ち件数とエラー詳細を確認してください。管理フォルダが置き換わった、またはアプリの記録と一致しないため、削除が拒否されている可能性があります。元ファイルが削除されたという意味ではありません。残ったコピーの所属を確認し、素材フォルダ全体を消さず、対象だけを扱ってください。

### 4.4 言語と地域に応じた表示 {#language-settings}

1. 「設定 → 一般 → 表示言語」を開きます。
2. 「システムに従う」、または 5 つの言語から選びます。
3. 保存に成功すると、アプリ自身の表示はすぐに切り替わります。アプリの再起動は不要で、壁紙の再生もやり直しません。

「システムに従う」は macOS の優先する言語の順序から、最初に対応するものを選びます。一致する言語がない場合は英語になります。数値の書式は現在の表示言語に従います。ファイル名、素材名、自分で付けたリスト名は翻訳されません。システムが提供するメニューやファイル選択画面は、macOS 側の言語で表示される場合があります。

アプリから「ユーザーガイド」を開き直すと、現在のアプリの言語で表示します。ガイド上部の言語選択は、読んでいる文書だけを切り替えます。

## 5. 困ったときは {#troubleshooting}

まず、問題が正式なデスクトップ壁紙、一時的なプレビュー、アプリの背景のどれで起きているかを確認してください。以下は簡単な確認から順に試せます。「詳細を表示…」があるエラーでは、内容を控えておくと対象の素材や操作を絞り込めます。

| 症状 | 考えられる原因 | 確認と対処 | 一時的な回避方法 |
| --- | --- | --- | --- |
| 壁紙が出ない／黒い | 未適用、表示先の違い、ファイルが読めない、デコード失敗、停止中 | ① 素材と表示先を選び直して適用。② 「Finder に表示」で実際に使用中のファイルを確認。③ メニューバーの停止理由を確認。④ 読める静止画で試す。⑤ その素材の確認エラーを読む | 表示できる画像を使うか、その画面の動的壁紙を停止する |
| 動画がカクつく／コマ落ち／消費電力が多い | 高い解像度やフレームレート、複数の独立再生、プレビューや変換との重複、発熱 | ① プレビューを停止。② 変換の完了を待つか不要なタスクを取り消す。③ 独立した動的画面を減らす。④ フルスクリーン背景を 30 Hz にする。⑤ 変換可能なら 1080p／約 30 fps 版を作る | 壁紙を一時停止するか静止画を使い、省電力時の停止をオンにする |
| 音量変更が反映されない | 全体ミュート、別の項目や一時設定を変更、音声トラックなし、出力先の違い | ① 全体・個別のミュートと音量を確認。② 現在の項目／表示先か確認。③ ライブラリ詳細で変えた場合は再適用。④ 元の動画と macOS の音声出力を確認 | 音声があると分かっている動画で試す。静かにしたい場合は全体ミュートを使う |
| 複数画面が一緒に変わる | 全画面同期を選択、以前の表示先が選ばれている、接続構成の変化 | ① 「ディスプレイ」で現在の画面を確認。② 1 台ずつ再生元を適用。③ 再接続後は対象を選び直す。④ 同期グループの共有を確認 | まず 1 台で設定を確認し、その後ほかの画面を設定する |
| ローカル Web が開けない | フォルダや開始ファイルの違い、リソース移動、外部依存、スクリプトの問題 | ① HTML/HTM が対象フォルダ内か確認。② 相対パスを確認。③ 必要なリソースを戻す。④ ローカル素材だけの簡単なページと比較。⑤ エラー詳細を確認 | 必要なファイルがそろったプロジェクトや別の素材を使う |
| Web 壁紙をクリックできない | 操作がオフ、権限不足や取り消し、Finder の空白部分以外をクリック | ① メニューバーで Web 操作をオン。② アクセシビリティと入力監視を確認。③ 許可後に再度オン。④ デスクトップの空白部分で左クリック | 操作しない壁紙として再生する |
| リストが進まない／切り替えがおかしい | 1 項目ループ、長すぎる時間や未保存、空のリスト、次の項目の準備失敗 | ① 再生モードを確認。② 時間・単位・回数を確認して保存。③ 素材の有無を確認。④ 次の項目が実際に使用するファイルを確認。⑤ 修正後にリストを再適用 | 順番再生と短い固定時間で試し、問題の項目を手動で取り除く |
| 応答しない／終了してしまう | 重い・問題のある動画や Web、変換の負荷、設定読み取り失敗 | ① 処理中か少し待つ。② 操作可能なら停止して通常終了し、開き直す。③ 応答しなければ macOS で強制終了して再起動。④ 簡単な画像で確認。⑤ 明確なライブラリ読み取りエラー時のみ下のリセットを検討 | 原因の素材を避ける。強制終了では未完了の変換が中断する点に注意 |
| 権限がないと表示される | Web 操作の未許可、ファイルや出力先へのアクセス不可、全画面キャプチャの制限 | ① エラーが示す機能を確認。② Web 操作はアクセシビリティと入力監視を確認。③ 読める素材／書ける出力先を選び直す。④ 初期の macOS 14 で全画面背景の画面収録許可が求められた場合は確認して再試行 | Web 操作をオフにするかフルスクリーンを終了し、通常の壁紙再生を使う |
| 言語が違う／一部未翻訳／切り替わらない | システムに従う設定、保存失敗、素材名の表示、一部エラーの翻訳不足 | ① 表示言語を明示的に選ぶ。② 保存エラーを確認。③ 該当ウインドウやガイドを開き直す。④ システム文字・名前とアプリのラベルを区別する | 別の対応言語を一時的に使う。自分のリスト名は変更可能。新規ライブラリの初期リスト名は「我的播放列表」のままの場合がある |
| システム壁紙が同期されない／停止後も画像が残る | 同期がオフ、正式適用待ち、同期失敗、最後の画像を保持する動作 | ① スイッチと各画面の状態を確認。② 壁紙を正式に適用。③ ファイルや画面の問題を直し、同期を再試行。④ 別画像に戻すなら macOS の壁紙設定で選ぶ | 同期をオフにしてシステム壁紙を選び直す。オフにするだけでは以前の画像に戻らない |
| 素材がライブラリから消えたがローカルコピーが残る | 削除待ち、またはフォルダとアプリの記録の不一致 | ① 「設定 → ストレージ」で削除待ち件数を確認。② エラーを保存し、不要な管理コピーか確かめる。③ アプリを再起動して再試行。④ 失敗が続く場合、確認した残存コピーだけを扱う | 当面はファイルを残し、素材フォルダ全体を削除しない |

**ライブラリを読めない場合の「バックアップしてリセット」**

ライブラリを読み込めないと明示された場合に限って使ってください。既存の設定をバックアップした後、素材の記録、リスト、ディスプレイへの割り当て、ライブラリ内の設定を初期化します。元の素材ファイルは削除しません。再度読み込みと設定が必要です。設定画面を開ける場合は、まず「詳細設定」で設定ファイルを探して別にコピーしてください。黒画面やコマ落ちへの最初の対処としてリセットしないでください。

## 6. パフォーマンスと消費電力 {#performance}

- **バッテリーを優先する**：低電力モード時の停止をオンにし、高温時の停止も維持します。動きが不要なときや長く席を離れるときは、メニューバーから一時停止します。
- **CPU／GPU の負担を減らす**：CPU は一般的な計算、GPU は画像処理を担当します。画面の用途に合った解像度とフレームレートを選びます。変換可能な場合は、1080p 設定が再生負荷の軽減に役立ちます。
- **画面の用途で使い分ける**：メイン画面を動画、サブ画面を画像にすると、すべての画面で別々の高解像度動画を再生するより軽くなるのが一般的です。同期でも画面数とサイズに応じた負荷は残ります。
- **処理を重ねすぎない**：確認後はプレビューを停止します。変換中にカクつく場合は壁紙を一時停止してください。フェードでは前後の素材を一時的に処理するため、負荷が気になる場合は即時切り替えを選びます。
- **全画面背景は必要に応じて**：まず 30 Hz を使い、滑らかさが必要な場合だけ 60 Hz にします。デスクトップ動画自体のフレームレートを制限する設定ではありません。
- **素材へのアクセスを安定させる**：安定して接続できるドライブを使い、Web リソースはローカルにまとめます。静止画のシステム同期が不要ならオフのままにします。

### 9.2 対応するファイル形式 {#formats}

| 種類 | 拡張子 |
| --- | --- |

### 9.3 システムと対応言語 {#requirements}

- システム：macOS 14.0 以降。
- プロセッサ：Apple Silicon（arm64）。
- 負荷は素材サイズ、フレームレート、ページの複雑さ、画面数によって変わります。用途に合わせた素材を選んでください。
- 対応言語：简体中文、English、日本語、Français、Español。

### 9.4 データの場所と保存範囲 {#data}

設定ファイルの場所は「設定 → 詳細設定」の「Finder に表示」で確認できます。アプリが管理する素材フォルダを手動で移動・置換しないでください。同期したシステム画像もアプリが別に保存します。

素材の記録、お気に入り、リスト、画面への割り当て、アプリ設定、削除待ち記録は保存されます。検索文字列、複数選択、一時プレビュー、手動停止の状態、未完了の変換キューは再起動後に引き継がれません。設定バックアップにメディアは含まれず、削除したコピーは復元できません。元の素材を保管するか、管理素材を別途バックアップしてください。
