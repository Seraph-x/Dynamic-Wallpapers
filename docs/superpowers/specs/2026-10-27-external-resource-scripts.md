# Complete external resource Script workspace design proposal

Status: completed approved design. The data-only foundation, actual renderer and
diagnostics, and complete workspace/native acceptance merged in PRs
[#41](https://github.com/Seraph-x/Dynamic-Wallpapers/pull/41),
[#47](https://github.com/Seraph-x/Dynamic-Wallpapers/pull/47) and
[#48](https://github.com/Seraph-x/Dynamic-Wallpapers/pull/48). The completion ledger
records tested revisions and evidence; unsupported runtime paths retain their
explicit read-only limitations.

## Complete delivery contract

Extend the existing source workspace to discover, inspect, check, add/change/remove, revert and navigate registered source anchors in owned material and particle files, whether originally loose or extracted from PKG. Every committed resource edit must survive one-step project undo/redo, save/reopen, immutable preview capture and loose/PKG export with actual playback in Editor preview and Main. Source originals and all unrelated bytes/metadata remain intact. Runtime exceptions and source availability are visible. All stages below are required before claiming this work package complete.

## Registered anchors and their runtime contracts

- Material resource `passes[0].constantshadervalues[exactKey]`: finite numeric scalar or 2/3/4-component numeric-vector bases consumed by an effect, mesh/per-mesh, generic tint, or particle material. Existing wrapper.script may be changed/removed; a known consumed constant can receive a new wrapper script. Other material passes remain discoverable with the exact current pin limitation instead of being falsely treated as rendered. Generic tint opacity/brightness require scalar bases and color requires vector3. Generic variants register only fields the actual tint path consumes; unsupported generic fields remain visible read-only with reason.
- Particle resource `children[N].instanceoverride[key]`: numeric rate/count/size/speed/lifetime/brightness/alpha and normalized colorn vector, with the same target-specific sink as actual particle overrides. Script registration binds the exact child system/instance, not every particle under a layer ID. Also register corresponding scene.instanceoverride anchors in the existing inline source API to avoid an inconsistent source catalogue.
- Particle resource `emitter[N].rate`: numeric wrapper scripts update that compiled emitter's rate, preserving burst/timing state, existing particles and the simulation pool. This gives particle-definition scripts a direct external-resource runtime sink without recompiling the whole model every frame.
- Any script-like field outside this registry is visible read-only with logical resource path/JSON pointer and the exact reason. User/animation-controlled wrappers retain existing binding protections. Do not hide an imported field, silently remove its binding, or claim compilation proves execution.

A registry describes supported paths, value kind, real runtime sink and source consumption state. Its matcher uses literal structural path arrays, not dot-string splitting; resource names and keys may contain dots/slashes/Unicode. No arbitrary history, file-count, recursion, source-length or operation caps are introduced.

## Data-only shared source modules

Add `Resources/SceneScript/json-spans.mjs` and `resource-contract.mjs` as pure build-time shared modules; both workbench and renderer consume the same anchor rules. Bundle into the workbench Script API and engine output; no network or additional installed runtime dependency. Use a stable virtual import specifier resolved by the existing esbuild plugin, rather than embedding machine-specific absolute paths in the patched upstream source/provenance.

The lexer accepts strict JSON or material/effect JSONC, with lexical states for strings/escapes, number/literal grammar, whitespace, line/block comments and trailing commas. It records container/member/value UTF-16 spans and original byte slices; the original UTF-8 BOM, whitespace, CRLF, unknown fields, unknown duplicate members and large-number lexemes are preserved. Duplicate selected keys or duplicated path ancestors are explicit ambiguous read-only anchors. Iterative traversal avoids invented nesting limits. Invalid UTF-8/Unicode or invalid grammar is a visible record error; imported bytes remain untouched.

Set replaces only the selected script string token. Add inserts only a script member (or wraps a recognized primitive while retaining its original literal). Remove deletes only that member and the necessary adjacent separator. JSON.parse may validate/decode individual known primitive spans, never serialize the whole document. The same unchanged source is a byte no-op and creates no staging/history entry.

## Discovery and resource transactions

`Editor/Web/resource-scripts.mjs` provides `discoverEditorResourceScripts(editor)`, which binds owner identity and snapshot around every await, plus lower-level asynchronous `discoverResourceScripts({snapshot,paths,read})` and pure inspection/patching APIs. It reads referenced model/material/effect/particle JSON, follows effect material and particle child edges with identity-based cycle detection, reads MDL material names through the existing codec, and inventories other JSON assets for unsupported script-like metadata. Referenced paths need not have a .json suffix. Original glTF/archive assets remain preserved and are shown as unconsumed/read-only. Validate path aliases and file/directory conflicts before resolving candidates.

Records contain `{kind,logicalPath,jsonPath,source,valueKind,state,consumers,resourceDigest,overrideVersion}`. Consumer identity contains the owning layer plus effect/mesh/particle child slot; a shared resource shows all affected consumers. Unknown references/read failures produce visible records, not a silently shortened scan. Cache only by complete document identity/snapshot and resource hash; asynchronous scans cannot replace a newer selection or erase a pending draft.

`captureResourceScript(editor,record)` owns the complete document snapshot and resource bytes/digest. `prepareResourceScript(source,edit)` validates the anchor/source and invokes the actual compile-only checker, producing proposed bytes without writes. `commitResourceScript(editor,proposal)` checks the capture before stage, awaits existing editor.stageResource on owned bytes, rechecks complete snapshot and resource identity after await and again inside editor.change, then performs one synchronous doc.transaction(doc => doc.resource(path,version)). Capture/proposal authenticity and byte ownership use private WeakMaps; mutable Uint8Array storage is never trusted from a caller or exposed as a writable proposal. Validate reserved paths/aliases with pure `SceneDocument.validateResource` before staging, so forged or reserved targets cannot even create a blob. A stale/failed stage keeps the draft and reports its real error; originals/history remain unchanged. The window's required resource session protects every staged version throughout this interval. No old unsafe native overload is reintroduced.

Generalize ScriptDraft behind a small inline/resource adapter while preserving the existing inline API/tests. Resource apply/remove are async at the workspace boundary, but history mutations remain synchronous. Selection switch, save, preview, undo/redo, export and close share the current flush barrier; a failed draft blocks the operation until actual correction or explicit Revert. The source chooser labels the logical file and anchor and shows shared-consumer impact, editable/read-only reason and scope. Keep the existing CodeMirror local history, completion/search, five-language layout, themes, keyboard/focus and 850×540 minimum layout. Value-aware templates must not feed Vec3 to vec4/scalar anchors; unavailable template semantics remain explicit.

## Actual runtime and provenance

Add a focused recorded patch module `scripts/scene-resource-script-patches.mjs` composed by `scene-engine-patches.mjs`. Extend scene-bundle provenance to hash all patch/helper inputs and exact match counts. Never modify the npm cache or its pinned entry hashes. Main, Editor workbench and Editor scene preview continue to carry identical shared engine bytes.

Propagate resource origin through actual readAsset/parseMaterial/effect/mesh/particle consumers using WeakMap metadata that user scripts cannot replace. Each origin includes logical path, JSON script path, original resource SHA256 and the exact compiled source. Material evaluation is keyed by resource origin plus actual consumer slot, so the same file used by two layers or two passes has the correct thisLayer and independent sandbox lifetime. A single typed constant evaluator serves effect, mesh, generic tint and particle paths; vector dimensions and scalar return values are checked before mutation. Invalid return/exception produces a structured diagnostic and no failed value write. Do not add a new silent static-value fallback. Preserve existing binding/script precedence, engine clocks, shared values and lifecycle/event/timer cleanup.

Child particle override scripts must target the bound child system rather than broadcasting through particleSystemsByLayer. Parent scripts apply only to systems actually inheriting that override object; an explicit child override (including an empty object) and event-child noninheritance must retain their authored precedence. The emitter-rate sink changes only the relevant compiled numeric field. New sandboxes use the same existing engine environment and hooks as corresponding inline anchors, are disabled under scripts:false, and are disposed on restart/load/close. Standard generic-particle material static fields need typed dynamic updates only where the pin really consumes those values; arbitrary shader constants execute through custom material uniform binding. No per-frame applyModel/_compile/pool rebuild.

## Structured diagnostics and source navigation

Extend the seven-field issue schema with an optional exact validated external `source` descriptor `{kind:'resource',path,sha256,pointer,text}`. Legacy inline issues remain seven-field; external issues have that eighth field. The descriptor comes from engine-owned original read/compiled-source metadata, never from an exception message or user callback object. Include descriptor identity in deduplication keys. Keep existing transport fragmentation/event budgets unchanged and validate source paths, digest, pointer types and Unicode at every JS/native boundary.

Update script-diagnostics.mjs, SceneProtocol.mm's strict JSON/schema validation, public header documentation, EditorScriptDiagnostic.swift and link serialization as one coherent protocol change. Native source links use the actual independent preview's exact compiled source descriptor; no second read from mutable editor Resources is needed. EditorCapturedScriptSnapshot continues to resolve inline captures and resolves external issues using their validated captured origin. Native preview labels the logical path and anchor; malformed/unknown origins remain explicitly unavailable.

Resource links add the validated resource descriptor to the tagged link shape. Reveal compares document identity, full resource digest, anchor and exact source against current editor.readResource. If current and no inputs are pending, open that resource source; otherwise use the existing separate read-only captured-source CodeMirror view. Never flush a pending editor input merely to inspect a captured source. Reported lines still follow the existing honest missing/out-of-range/import-transformed rules.

## Acceptance gates

1. Pure lexer tests preserve all untouched bytes for set/add/remove with JSON/JSONC, BOM, CRLF/mixed endings, escaped delimiters and comments inside strings, duplicate unknown fields, huge integer lexemes, prototype-looking keys, literal punctuation in paths, malformed grammar, invalid Unicode and deep nesting. Ambiguous selected paths reject without mutation.
2. Compile-only probes include bodies that would throw, mutate globals, fetch or import; none executes during discovery/check/apply. Unknown metadata is reported unvalidated rather than fake success.
3. Real resource transaction tests prove one undo record, redo, no-op, stage/hash error, stale-before/after-stage, document/load/close/freeze races, same shared resource across layers, and GC protection of pending/current/history versions.
4. Browser UI tests use actual input and CodeMirror: select material/particle/package-derived sources, check/apply/revert/remove, invalid draft recovery, dirty indicators, freeze/export barriers, focus-safe captured navigation, five languages/themes and minimum layout.
5. Shared renderer tests run real WebGL through the exact shared bundle: effect material, mesh/per-mesh, generic tint, particle material, external child overrides and emitter-rate scripts each visibly change the expected pixels/simulation. Workbench scripts:false executes none. Use owned deterministic fixtures; no mock renderer or fixed fake callback proves playback.
6. Native tests prove import -> edited logical override -> undo/redo -> save/reopen -> captured preview -> loose/PKG export -> actual Main playback for both material and particle resources. Compare original package/resource hashes and every unrelated JSON byte. Verify normal page/resource release and restart/close safety.
7. Resource-source errors navigate to the exact captured file/anchor, with stale resource digest, shared consumers, missing/ambiguous origin, malformed descriptor, long fragmented source and unknown line cases. No console-text matching.
8. Reproducible engine/editor builds, provenance and privacy/source-export checks pass; focused backend execution stays 60 seconds after separate cold builds, CEF harness build stays 180 seconds and each actual phase stays 60 seconds. Full suites follow repository settings. Only then claim external-resource scripting complete.
